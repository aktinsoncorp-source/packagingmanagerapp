# Packing list preferences

- Always use A4 paper for packing lists.
- Use one clearly separated bordered table per order. Show the Order ID once as the table header and keep all products for that order underneath it.
- Keep each entire order table together on one page.
- Include Employee:__________________ after the Order ID/Order Number, followed by the blank Number and Time underlines inside each order table header. Staff write their own number to link the packing list to the printed waybill, and the packing completion time.
- Include product name, variation, and number of pieces. Preserve source batch grouping.
- At the end of every generated packing document, add a product picking summary after a page break. Apply the saved Define Name alternatives independently to product name and variation; blank alternatives retain their original fields. Combine matching final product names and variations only within that generated document. Preserve original source data and fingerprints in processing history, plus a separate immutable snapshot of the printed names.
- Use light orange order headers and light peach column headers with dark text for SPX/FLASH. Product line-item rows alternate white and light gray.
- For Lazada, use the Order Number as the order header and omit Tracking ID. Use blue order and column headers with dark text and alternating white/light-gray product line-item rows, while keeping the same A4 order grouping and handwritten Number and Time fields.
- Combine Lazada and TikTok in one document for each processing batch, using the blue theme and clear platform section labels. Retain Lazada Order Number and TikTok Order ID as appropriate. Use a shared `LAZADA_TIKTOK` filename sequence. Mark earlier standalone outputs as superseded in the processing log when a combined replacement includes their orders.
- Save all finished packing documents together in a `000 Output` subfolder of the existing dated source folder, for example `20260926/000 Output`. Do not create separate carrier output folders or a parallel year/month/day directory tree.
- End each packing document filename with a sequence suffix before `.pdf`. For each output group and date (SPX, FLASH, or combined LAZADA_TIKTOK), use one above the highest numbered PDF or Word file still present in `000 Output`, or `_1` if none remain. Reuse a deleted trailing number but do not fill a lower gap: existing `_1, _2` produces `_3`; existing `_1, _3` produces `_4`. New exports are PDF only; existing Word files still count toward the sequence. Never overwrite an existing file.
- Maintain `Processed_Files.txt` in that dated `000 Output/.PackingData` hidden folder, recording each completed output and its source PDFs. Check this log before processing later arrivals, and include only newly added unprocessed files unless the user requests a reprint or revision. Review changed source files explicitly rather than silently treating them as new or unchanged.
- The existing Windows program is authorized. Save completed version checkpoints locally in Git, with a verified bundle in Git/vVERSION. Preserve earlier version folders; do not upload without authorization.

- Define Name stores uppercase single-line fields, trims trailing spaces, and matches original pairs without case sensitivity. Confirm before merging rows with equal nonblank alternative product AND variation. Keep the first selected base and every linked original pair; later PDF scans must recognize all links. Excel round trips must preserve and permit editing those linked originals.

- Shopee continuation labels with the same Order ID and consecutive printed item numbers belong to one order. Reject missing, overlapping or duplicate sections instead of silently dropping products.
- Each Shopee PDF has Auto/SPX/FLASH courier selection. Auto takes the nearest exact SPX or FLASH folder first, then filename/path hints. Explicit per-file selection overrides Auto and persists until reset or PDF contents change. Lazada/TikTok cells show a disabled dash.
- Scan compatible PDFs anywhere under the selected dated folder except 000 Output. Hide unrecognized/no-readable-text PDFs; keep genuine errors in recognized packing lists visible for review.

- Main screen labels have no step numbering. Generate exports PDF only with no format-selection dialog; the public engine must reject Word export requests. Existing PDF and Word outputs retain their history and numbering coverage.
- Before generating repeated orders (earlier dated history or overlapping source PDFs), show the requested warning with a large centered No button as Enter/Escape default. Below it, place smaller light-gray borderless text reading Continue to Generate the Repeated Orders, centered within the No button width. Matching orders print once per run. Backend confirmation is tied to the selection and output format.
- Define Name opens locked each time with icon-only closed/open padlocks. Locked mode permits search/view but disables changes and Excel editing. Unlock explicitly; save before relocking.
- Use [     ] for Done boxes in both packing tables and picking summaries. Show dynamic totals for checked PDFs, distinct order IDs below the main list; omit the Pieces column and piece totals from the main list, with the selected platforms only.

- Completed source rows show only Process again in Status. Deleted outputs clear active processing coverage and make uncovered orders new again; retain immutable audit snapshots. Retain review errors for orders with surviving outputs. Use alternating white/light-gray product rows in both order tables and picking summaries; preserve platform-colored headers and summary totals.

- In the repeat warning, No generates only orders without an existing matching output; the gray continuation link includes earlier generated orders too. Enter/Escape choose No. If all selected orders are already covered, return a clear no-new-orders message and create no empty document. Missing output files remain regeneratable; new overlapping source orders print once. Do not show the sentence about matching orders appearing once in the warning.
- Keep the Define Name closed/open outline locks aligned on the same baseline, without enclosing circles or keyholes. Preserve existing lock behavior.
- Keep performance changes local and retain source hashing, order/quantity verification, A4, whole-order and summary-row pagination checks. A summary wholly on one page proves that its rows do not split; multi-page summaries still require row checks.

- Store processing history, readable log, date lock, courier choices, transaction journal and new staging folders in Windows-hidden 000 Output/.PackingData. This is persistent data, never temporary cleanup. Migrate legacy root records under the date lock using resumable renames; preserve conflicting copies and report an error rather than overwriting. Generated documents remain directly in 000 Output. Open processing log must read its hidden path. Preserve legacy interrupted transaction paths during recovery.

- Output documents show their total order count above batch/platform headings. Keep batch labels and source filenames, without per-batch order counts.

- Export Item Sales creates a date-first Excel quantity report in the dated 000 Output folder (YYYY-MM-DD_Item_Sales_N.xlsx), with units per item/variation and original order details. Use the full selected date, current Define Name alternatives, platform/order deduplication, and source-PDF unit prices when available; never guess absent prices. Sales export does not mark orders processed. Each export is a full-date snapshot for ERP replacement, not an incremental import. Preserve existing files and the same app version unless a new version is requested.

- Define Name product headings sort A-Z/Z-A; variation headings sort recognized mL/L and g/kg sizes ascending/descending within unit families. Show row numbers, persistent entire-definition row locks, all-lock/unlock icons beside original product names, and yellow unsaved-row highlighting. Locked definitions and linked originals cannot be edited/deleted/merged through the UI or Excel until explicitly unlocked. Correct invalid leading spaces/symbols in alternatives automatically; retain independent blank fallback and single-line validation.

- Define Name Excel export must include all rows even when individual rows are locked. Preserve cell protection and import validation; do not unlock finished definitions to export. Skip formatting operations that Excel disallows on protected worksheets.

- When Define Name opens, individual rows default locked only when both alternative product name and alternative variation are nonblank; blank or partial pairs start unlocked. Explicit row unlocking remains effective for that session, including saves/exports. Reopening reapplies these completion-based defaults.

- Different new alternatives on unlocked linked Excel originals must import without a conflict warning: separate their complete alternative pairs into definitions while preserving every original, omitted pair, and the base ID. A single changed shared alternative still propagates. New matching definitions merge only after confirmation in the app; locked originals remain protected.

- Pasting or sorting only the visible Excel columns must not assign leftover hidden IDs to other products. Match an original still present elsewhere in the workbook by its visible product/variation; retain genuine renames, all originals, base IDs and lock protection. When repairing a pasted/reordered inventory list, preserve its complete per-original alternative pairs before app merge confirmation; ordinary linked-row shared edits retain their existing propagation behavior. Excel filter sorting includes the hidden identity columns.

- Define Name sorting has two independent choices: original/alternative product name for primary groups and original/alternative variation for sizes within each group. Each heading toggles only its own family direction; switching that family's field starts ascending and retains the other sort. Show black arrows, A-Z/Z-A or smallest/largest labels, and the next action. Preserve locks, selections and unsaved-row highlights while sorting.

- SPX/FLASH packing order rows include Unit Price and Total Price. Preserve the source PDF's printed total when available; otherwise calculate it exactly from known unit price and pieces. Unknown prices show a dash. Retain A4, whole orders, themes, quantity-only picking summaries and original fingerprints; preserve both source price fields in audit snapshots. Lazada/TikTok packing columns remain unchanged.
