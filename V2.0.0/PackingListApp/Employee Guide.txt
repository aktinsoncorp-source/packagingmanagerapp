PACKING LIST MANAGER 2.0.0

INSTALL
Double-click Packing List Manager Setup 2.0.0.exe and follow the setup screens.
Setup installs in C:\Program Files\Packing List Manager and requests administrator
permission. Run setup again to reinstall/update; close the app first. Daily use
does not need administrator permission. No separate Python installation is needed.
Microsoft Word desktop is required to create and verify packing PDFs.
Microsoft Excel desktop is needed only for editing definitions with Excel.

PORTABLE COPY
Extract the entire portable ZIP to a writable folder, then open Packing List Manager.exe.
Keep App Files, ProductNames.json and SkuCatalog.json with the application.

DAILY USE
1. Open Packing List Manager from its shortcut or application folder.
2. Choose your main packing folder and the packing date.
3. Check Use beside the PDFs to include. Click Use in the heading to select all.
4. Review any highlighted issues. Define Names shows the inventory Product Name
   and Size attached to each SKU; Ecommerce Details shows its website descriptions.
5. Click Generate Packing Lists. Finished A4 PDFs appear in that date's 000 Output.

Lazada shows Order Number and Tracking Number. Separate tracking numbers remain
separate shipment tables even when the order number is the same.
If repeated orders are found, No includes only orders without a matching output.

PRODUCTS AND UPDATES
This package includes your approved SKU catalog and saved product definitions.
Installing again preserves existing ProductNames.json, SkuCatalog.json and settings.
For installed copies, back up those files from %LOCALAPPDATA%\Packing List Manager.
An existing per-user V2 installation's names/settings are copied on first launch.
Portable copies keep data beside the executable. Existing data is never replaced.
Uninstall removes program files but keeps your saved product data. Source PDFs,
generated packing lists and their dated processing histories are never removed.

FIRST START
Choose your usual packing folder. The installer does not include test PDFs,
test orders, earlier outputs or a preset folder belonging to another computer.
