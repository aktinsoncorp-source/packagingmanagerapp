Packing List Manager 2.0.0

Station Board interface: graphite gray/off-white, readable dividers and a loading bar.
SKU-based Product Name and Size definitions with viewable ecommerce details.
Review reminders and automatic unlocking for undefined or missing-SKU products.
Flash outputs use pastel yellow; SPX remains orange; Lazada/TikTok remain blue.
Lazada Order Number + Tracking Number preserves separate parcels and audit records.
A4 PDFs, whole-order/shipment tables, picking summaries, repeat checks and sales export.

Packaged Python/Tk application with a private runtime; no Python setup needed.
Per-user Windows installer and portable ZIP. Existing product data survives reinstall
and uninstall. Microsoft Word desktop remains required for verified PDF export;
Microsoft Excel desktop is needed for live Excel editing.

Application name, executable filename and version remain Packing List Manager 2.0.0.
