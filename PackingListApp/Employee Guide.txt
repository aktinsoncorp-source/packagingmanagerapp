PACKING LIST MANAGER
Employee guide - version 1.8.0
Help updated September 28, 2026

Start
Double-click Packing List Manager.exe. Keep the App Files folder beside it.
This program runs on this Windows computer. Microsoft Word is used to check
the packing document layout and create PDF exports. Python and ChatGPT are not needed to use it.

Folder format
Use one main folder, with a separate dated folder for each processing day.
The main folder can be called Packing Files, My Orders, or another name.

The dated folder must use YYYYMMDD: exactly eight digits, with a valid year,
month and day. For example, September 27, 2026 is 20260927.
Use 20260927, rather than 2026-09-27, September 27, or separate 2026\09\27
folders. The date displayed in the app is 2026-09-27, but its folder name
is 20260927.

Recommended folder and file layout:

Packing Files\
  20260927\
    SPX\
      20260927_SPX_PL_1.pdf
      20260927_SPX_PL_2.pdf
    FLASH\
      20260927_FLASH_PL_1.pdf
    LAZADA & TIKTOK\
      20260927_Lazada_PL_1.pdf
      20260927_TikTok_PL_1.pdf
    000 Output\
      SPX_Packing_Checklist_2026-09-27_1.pdf
      FLASH_Packing_Checklist_2026-09-27_1.pdf
      LAZADA_TIKTOK_Packing_Checklist_2026-09-27_1.pdf
      Processed_Files.txt
      Processing_History.json

The program creates 000 Output and its completed documents/history as needed.
Source PDFs can go directly in the dated folder or in ANY of its subfolders,
including SPX, FLASH, TIKTOK, LAZADA or other folder names. The scanner reads
compatible PDFs throughout that dated folder and skips everything in 000 Output.

Choose folder and Select date
- Choose the main folder (Packing Files), then select the processing date.
  With September 27 selected, the app scans Packing Files\20260927.
- You can also choose the dated folder itself (20260927). The app sets the
  date automatically and displays its parent as the main source folder.
- Choose the main folder or dated folder, not SPX, FLASH, LAZADA & TIKTOK,
  or 000 Output. Those folders belong inside the dated folder.
- The date chooses the processing folder. Orders inside its PDFs can have
  earlier order dates. The app does not sort PDFs by dates in their names.
- If that day's folder is new, Add PDFs creates it and the platform folders.

Source PDF filename format
For consistency, use: YYYYMMDD_PLATFORM_PL_BATCH.pdf
Here PL means packing list. BATCH is 1, 2, 3, and so on as new PDFs arrive.

Examples:
  20260927_SPX_PL_1.pdf
  20260927_FLASH_PL_1.pdf
  20260927_Lazada_PL_1.pdf
  20260927_TikTok_PL_1.pdf

This filename pattern is recommended, not compulsory. The file must be an
original packing-list PDF with readable text; .pdf and .PDF are accepted.
The platform is recognized using the PDF layout and the courier rules below.
Renaming a screenshot, image, Word document or waybill to .pdf does not make
it a supported packing list.

How the program recognizes each platform and courier
The PDF contents identify Shopee, Lazada or TikTok. Folder names do not turn
an unrelated PDF into a packing list.

Shopee rows have a Courier dropdown: Auto, SPX or FLASH. Auto is the default.
- Auto first uses the nearest enclosing folder named exactly SPX or FLASH.
  Folder names are case insensitive. SPX/PACKING LIST 1.pdf becomes SPX;
  FLASH/PACKING LIST 1.pdf becomes FLASH. A folder wins over the filename:
  FLASH/SPX_orders.pdf still becomes FLASH with Auto selected.
- Without an exact courier folder, Auto looks for one separate SPX or FLASH
  label in the filename, then an unambiguous label in the remaining path.
  SPX_Orders.pdf works; SPXOrders.pdf does not provide a separate label.
- The Platform column shows the courier Auto selected. The Courier dropdown
  continues to display Auto so it follows the folder automatically.
- A generic Shopee PDF outside these folders still appears, with its order
  and piece counts. If Auto cannot identify a courier, choose SPX or FLASH
  in that row before ticking Use and generating.
- Choosing SPX or FLASH manually overrides the folder/filename for that PDF.
  Choose Auto again to restore automatic folder recognition.
- Manual choices survive rescanning and restarting the app. Replacing the
  PDF contents resets its choice to Auto, so check the courier again.

Lazada and TikTok are recognized from the PDF contents anywhere in the dated
folder. Their Courier cells show a disabled dash. They share a blue output.
Unreadable, scanned/image-only, corrupt and unrecognized PDFs are hidden
from the selection list. Recognized packing lists with invalid or incomplete
order data stay visible with an error for review.

Adding PDFs from Downloads or another folder
Click Add PDFs to copy files into the selected dated folder automatically.
Identified Shopee files go into SPX or FLASH. Generic Shopee PDFs with no
courier clue go directly into the dated folder: choose the courier in their
row after adding. Renaming is optional. Lazada and TikTok are recognized by
contents and copied into their shared platform folder. Originals stay in place.

Checking a different folder
1. Keep the same YYYYMMDD structure inside the new main folder.
2. Click Choose folder, check the selected date, and click Scan for new PDFs.
3. Confirm the expected filenames, platform labels and order counts appear.
   If no files appear, check the dated folder name and source PDF location.
   If a row needs attention, read its message before generating.
When moving previously processed work, copy the entire dated folder,
including 000 Output, its completed PDF/Word documents, both history files, and
Courier_Selections.json if present (the saved manual courier choices).
Older batches made before this app may have only Processed_Files.txt; keep
that log and their Word documents. The app verifies that earlier history.
Copying only PDFs into a fresh dated folder can make them appear unprocessed.

Daily steps
1. Click Choose folder and select your main packing folder, or the dated
   folder (for example 20260926). Check the date shown on screen.
2. Save downloaded PDFs anywhere inside the selected dated folder, or click
   Add PDFs. SPX and FLASH subfolders let Auto select the correct courier.
   For a generic Shopee file elsewhere, choose its Courier in the table.
3. Click Scan for new PDFs. New files and files missing their generated output
   are selected automatically. Processed files stay selectable: tick Use
   to generate them again. Click the checkbox in the Use column header to
   select all compatible PDFs, including processed ones. Click it again to
   clear all selections. A partial check means some eligible rows are selected.
   Files with errors, no identified courier, or awaiting changed-file review
   are excluded until resolved. Check the Platform and Courier columns.
   To view a file's contents, select its row and click Open selected PDF.
4. Click Generate Packing Lists. Choose PDF (the default) or Word (.docx),
   then click Generate. The format starts at PDF each time you open this choice.
   Microsoft Word checks A4 layout for both formats and creates the PDF export.
   Only your chosen format is saved into 000 Output and Completed documents.
5. If a repeat warning appears, No is selected by default. Enter, Escape or
   closing the warning cancels. Click the smaller Yes button only when you
   intend to generate those orders again. No creates no completed documents.
6. Open and print the PDF in your PDF viewer, or open the Word file in Word.
   Use A4 paper.

What is generated
- One document in your chosen format for SPX and one for FLASH, with orange tables.
- One combined document for Lazada and TikTok, using blue tables and
  separate platform labels. A batch containing only one of these platforms
  still uses the LAZADA_TIKTOK filename sequence.
- All files go in the selected dated folder's 000 Output folder.
- Each group uses the next suffix: _1, _2, _3, and so on, followed by .pdf or .docx.
  PDF and Word share one sequence: _1.pdf followed by a Word export gives _2.docx.
- Output suffixes are assigned by the program independently of the numbers
  in source PDF filenames. Keep the generated output and history filenames.
- The source PDF batches stay grouped. Each order has one bordered table,
  Employee, Number and Time writing lines, product check boxes [     ], variation
  and pieces. Picking-summary Done boxes have the same wider writing space.

Processed format in Status
Processed rows show Processed - PDF, Processed - Word, or Processed - PDF + Word.
The formats refer to completed files that still exist and contain the current order
versions. Scan again after deleting a file: the status drops the missing format, or
shows Output missing when no current output remains. Earlier superseded revisions
are excluded. If only some orders have an output, the status says Some orders and
shows the available format. Processed rows remain selectable for another generation.

Selected totals
Below the PDF list, Selected shows the number of checked PDFs, orders and pieces.
It updates immediately when you tick or untick Use, or use the select-all checkbox.
Only checked platforms are listed: SPX, FLASH, LAZADA and/or TIKTOK. Highlighting a
row without ticking Use does not add it to the total. Matching order IDs across
checked PDFs are counted once, just as they will be printed once in that run.
An overlapping order is assigned to the first selected source used for generation.

Repeated-order warning
The program checks order IDs against this dated folder's earlier generation history
and other readable source PDFs in the same dated folder, including unchecked files.
Previously generated orders still trigger the warning if their output was deleted.
The warning says:
Warning: There are orders in this packing list that has repeated. Do you wish to
continue and generate the repeating orders again?
No is the larger, highlighted default. Yes is smaller. Choose Yes only for an
intentional reprint or revised batch. The program checks again after confirmation
if the selection has changed. Identical overlapping orders print once per run.
History checks are per dated folder; they do not search other dates or computers.

Product picking summary
Every generated document ends with a Product Picking Summary on a new page.
It lists the product, variation or size, and total pieces needed from inventory.
Each summary covers ONLY the orders in that document. Later batches get their
own summaries covering the PDFs selected for that run. Regenerating a PDF
also includes its orders again in that new document and summary.
The packing tables and picking summary use the names saved in Define Name.
A blank alternative product name keeps the original product name; a blank
alternative variation keeps the original variation. Each field works separately.
A dash represents a missing source variation. Sizes are not inferred or added.
Matching FINAL product names and variations have their pieces added together
in that document's picking summary. Define the same alternatives for different
listings only when you want their quantities combined. Pieces means packs or
bottles, not kilograms or liters. Use the Done boxes while collecting stock.
Long summaries continue onto additional A4 pages with repeated column headers.

New orders later in the day
Add the new PDFs and scan again. Generate creates the next batch.
Give later source PDFs a new filename, such as 20260927_SPX_PL_2.pdf, and
keep them in the same day's SPX folder. Keep earlier source files in place;
replacing a processed PDF triggers a changed-file review.
Existing batches are kept. Generating includes all orders in the selected
PDFs, including previously generated orders. An order repeated across the
PDFs selected in the same run appears once. Uncheck PDFs you do not want.
A renamed copy is identified as repeated and stays unchecked by default;
you can still tick it to generate another copy.

Generating or printing an earlier batch again
To make another copy, tick Use beside any processed PDF and click
Generate Packing Lists. Choose PDF or Word and confirm the repeat warning only
when a new copy is intended. You can combine it with other selected PDFs.
Each platform uses one more than its highest PDF or Word filename number still in
000 Output. Existing files are never overwritten.
Examples for one platform:
- No generated PDF or Word files remain: the next file is _1.
- _1 and _2 remain (you deleted _3): the next file is _3.
- _1 and _3 remain (you deleted _2): the next file is _4.
Gaps below the highest remaining number are not filled. SPX, FLASH, and
LAZADA_TIKTOK have separate numbering for each date.
To print an existing PDF or Word document, use Completed documents instead.

If you delete a generated PDF or Word file
Click Scan for new PDFs. The program checks which PDF or Word files still exist
inside this date's 000 Output folder and matches them to their source PDFs.
If orders no longer have a current output document, the affected PDF rows show
Output missing and are selected automatically. Click Generate Packing Lists
to create a new numbered copy from those selected PDFs.
If another current copy still covers every order, the PDF remains Processed;
you can tick Use to generate it again anyway. A superseded revision does not
count as a current copy. Moving or renaming a generated file away from its recorded
name in 000 Output is treated as missing.
A PDF may contain both covered and missing orders. When selected, its full
contents are included in the new document. Its picking summary matches that
new document only.
Completed documents shows only PDF or Word files that still exist. Missing entries
are removed when you open the list, click Refresh list, or scan again.

Using Completed documents
The groups appear in this order: SPX, FLASH, Lazada + TikTok. Within each
group, files appear in numeric order: _1, _2, _3 ... _10.
Click the + beside a generated file to expand its included source PDFs.
Expand a PDF to see its order IDs, then expand an order to see the printed
product names, variations and pieces included in that document.
The displayed data belongs to that generated document, even if the source
PDF was changed afterward. If two selected PDFs share an order, that order
can appear beneath both source PDFs, but is printed once in the document.
Select any document, PDF or order and click Open document to view its
packing list. Select a source PDF or its order to use Open source PDF.
Refresh list removes any generated files deleted while this window is open.

How the file history works
Every generation records the selected source PDF paths, their file
fingerprints, linked order IDs, and the output filename containing those orders.
Both the readable log and Processing_History.json retain these associations.
Scan also saves associations from earlier logged batches before a completed file
is deleted. Keep the source PDFs and both history files so these links remain
available; you do not need to delete history to generate again.
Changed PDFs still require Review changed file before their current contents
can replace an earlier version. Deleting a generated output does not bypass review.

Changed files - supervisor review
A changed file is marked for review and is not selected automatically.
Click Review changed file to compare the earlier and current order details.
- Keep earlier output records a decision to ignore the changed version.
- Create revision selects the changed file for a new, clearly marked
  revision document. This includes the file's orders again: check their
  previous packing status before using it. Click Generate to create it.
The log records which earlier orders or documents the revision replaces.
Conflicting versions of an order in two current PDFs must be resolved by
the supervisor before those PDFs can be processed.

If a file needs attention
Read the Status column; hover over a shortened message to see it in full.
Shopee continuation labels with the same Order ID are joined into one order
when their printed item numbers continue in sequence. For example, items 1-9
followed by items 10-11 become one 11-line order and one picking-summary total.
Missing or overlapping item numbers, duplicate complete labels, unreadable
quantities and multi-package labels still need review. Download the original
packing list or ask the supervisor to review it. Missing data is not guessed.
If an expected PDF is absent, confirm it is an original supported packing list
with selectable/readable text, rather than a waybill or a scanned image.
If an order cannot fit on one A4 page, no completed batch is recorded.
If Word needs setup or shows a dialog, finish that in Word and try again.

Files to keep
Keep source PDFs, completed PDF/Word documents, Processed_Files.txt and
Processing_History.json together. Keep Courier_Selections.json too when present.
Back up the whole dated folder.
The text log is readable. The JSON file stores exact fingerprints and order
history for the program. Do not manually edit or delete either history file.
A .packing-transaction.json file means a batch commit was interrupted; the
app recovers it on the next scan. Leave it in place for the app to recover.

Moving the application
Copy the whole Packing List Manager folder. Use Choose folder on the new
computer to select the dated source folders. Word must be installed.
The current workflow is designed for one operator on one computer at a time.

Supported sample layouts
Shopee: A4 PDFs with up to four packing labels per page (SPX and FLASH).
Lazada: order-level packing lists with four item columns.
TikTok: one order per page with Product Name, SKU, Seller SKU, Qty and Qty Total.
If an online shop changes its PDF format, the parser may need an update.

Define Name - standard product names
Click Define Name near the bottom of the main window. Definitions apply across
platforms, dates and source folders. Matching ignores letter case and trailing
spaces. Unsupported PDFs do not add guessed items.

The editor opens LOCKED every time. The closed-padlock and open-padlock icons have
no text labels; hover over them for a tooltip. Click the open padlock to unlock.
While locked, you can search and view linked originals, but cannot edit, add, delete,
save, export to Excel or import. After unlocking, Export starts enabled and Import
stays disabled until an Excel session is opened, as described below.
Save your changes before clicking the closed padlock to lock again. If an Excel edit
is pending, import it or close the editor first. This lock prevents accidental edits;
it does not require a password. Closing and reopening always restores the lock.

All four name fields are converted to UPPERCASE. Spaces at the end are removed;
spaces between words remain. Enter a single line only: paragraphs, line breaks,
and tabs are rejected. Long names may wrap on screen for readability; that does
not insert a line break into the saved name.

The alternative columns are highlighted orange. You may edit all four columns,
add a row, or select rows and click Delete selected. Click Save names to apply.
Blank alternatives fall back independently to the original product or variation,
in uppercase. A nonempty alternative must begin with a letter or number, with
no leading space or symbol. These common symbols are allowed afterwards:
- ( ) / % . + , & apostrophe.

Merging matching definitions
When Save names or Excel Import finds definitions with the SAME nonempty
alternative product name AND alternative variation, it asks whether to merge.
Case differences and trailing spaces do not make the alternatives different.
- Yes: keep one definition and remember ALL its original product/variation pairs.
- No: save the edits but keep the definitions separate.
- Blank alternative fields never trigger a merge.

To choose the base, select its row first, then Ctrl-click any other rows you
want selected. Save names checks every matching alternative pair, including
unselected rows. Within each matching group the first selected row is the base;
if none is selected, the first listed row is used. Excel imports use the first
matching definition in worksheet order. The confirmation shows the base before
you choose Yes. Names always use uppercase after normalization.

The Original pairs column shows View (N). Click it to see every linked original
pair, with the base first. Search also finds the linked originals. Later scans
recognize all linked originals and do not recreate separate definitions for them.
Changing the shared alternatives updates how every linked pair prints.

Deleting a definition and saving removes its alternatives and ALL its linked
originals. If any original pair appears in a later scan, it returns as a NEW,
separate definition with blank alternatives. Opening Define Name or exporting
alone does not rediscover deleted pairs.

Temporary Excel editing
Desktop Microsoft Excel is required for these two small buttons.
1. Unlock the editor with the open-padlock icon. Export becomes enabled; Import
   starts disabled.
2. Click Export. Direct edits are saved, including any merge confirmation, and
   the program opens Excel from an internal temporary folder. Export becomes
   disabled and Import enabled. The program's grid pauses editing.
3. Excel includes ONE ROW PER ORIGINAL PAIR, including every linked original in
   a merged definition, so all original names and variations can be edited.
   These rows remain one merged definition when imported. Keep the Names sheet,
   four visible headings and hidden identification columns intact.
4. You may edit the four name columns or add new rows. Changing an alternative
   in one linked row updates that alternative for the entire merged definition.
   Conflicting new values on linked rows are rejected; use one shared value.
   Omitted Excel rows remain in memory; delete definitions through the program.
5. KEEP THE EXCEL WORKBOOK OPEN. Finish editing the cell, then click Import.
   The program saves Excel, normalizes/validates all names, asks about any new
   matching definitions, and saves. It closes only that workbook, deletes its
   temporary file, then enables Export and disables Import again.
6. If you closed the workbook first, Import displays:
   Error: No file has been detected
   Please do not exit excel file before clicking import
   The buttons reset. Export again to start from the saved names.

Invalid names, duplicate original pairs, conflicting linked edits, changed
headings or formulas stop the import without changing saved names. Keep Excel
open, correct the reported rows, and Import again. Use plain text. Multiline
Excel cells are rejected. Other open Excel workbooks remain open.

Generated documents
Changes affect FUTURE generated documents. Existing documents and their saved
printed contents stay unchanged. To apply new names to a processed PDF, select
its Use checkbox and generate another document. Matching final product/variation
pairs combine in that document's picking summary. Original PDF data, quantities,
and source fingerprints remain unchanged.

Saved definitions
ProductNames.json beside the program stores the definitions and linked original
pairs. ProductNames.json.bak keeps the preceding saved catalog. Keep these with
the application when moving or backing it up. Version 1.6 upgrades the existing
catalog to uppercase with its IDs and deletions preserved, and keeps a backup.
If the catalog is unreadable, restore a valid backup; it is not silently replaced.
The temporary Excel workbook is an editing session, not a backup.

Employee field on every order (version 1.6.1)
Every newly generated SPX, FLASH, Lazada and TikTok order header now reads:
Order ID / Order Number, Employee:__________________, Number, Time.
Write the name of the person who packed that order on the Employee line.
The employee field appears after the order identifier and before Number.
Existing Word documents keep their saved layout. To add the field to an older
batch, select its source PDFs again and generate a new numbered document.
