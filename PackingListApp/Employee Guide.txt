PACKING LIST MANAGER
Employee guide - version 1.5
Help updated September 27, 2026

Start
Double-click Packing List Manager.exe. Keep the App Files folder beside it.
This program runs on this Windows computer. Microsoft Word is used to check
the packing document layout. Python and ChatGPT are not needed to use it.

Folder format
Use one main folder, with a separate dated folder for each processing day.
The main folder can be called Packing Files, My Orders, or another name.
For easy courier recognition, keep SPX and FLASH out of the main folder's
name; use them for the separate courier folders shown below.

The dated folder must use YYYYMMDD: exactly eight digits, with a valid year,
month and day. For example, September 27, 2026 is 20260927.
Use 20260927, rather than 2026-09-27, September 27, or separate 2026\09\27
folders. The date displayed in the app is 2026-09-27, but its folder name
is 20260927.

Recommended folder and file layout:

Packing Files\
  20260927\
    SPX\
      20260927_SPX_PL_1.pdf
      20260927_SPX_PL_2.pdf
    FLASH\
      20260927_FLASH_PL_1.pdf
    LAZADA & TIKTOK\
      20260927_Lazada_PL_1.pdf
      20260927_TikTok_PL_1.pdf
    000 Output\
      SPX_Packing_Checklist_2026-09-27_1.docx
      FLASH_Packing_Checklist_2026-09-27_1.docx
      LAZADA_TIKTOK_Packing_Checklist_2026-09-27_1.docx
      Processed_Files.txt
      Processing_History.json

The program creates 000 Output and its completed documents/history as needed.
Place source PDFs in the platform folders, outside 000 Output. The scanner
reads PDFs inside the selected dated folder and its subfolders, and skips
everything inside 000 Output.

Choose folder and Select date
- Choose the main folder (Packing Files), then select the processing date.
  With September 27 selected, the app scans Packing Files\20260927.
- You can also choose the dated folder itself (20260927). The app sets the
  date automatically and displays its parent as the main source folder.
- Choose the main folder or dated folder, not SPX, FLASH, LAZADA & TIKTOK,
  or 000 Output. Those folders belong inside the dated folder.
- The date chooses the processing folder. Orders inside its PDFs can have
  earlier order dates. The app does not sort PDFs by dates in their names.
- If that day's folder is new, Add PDFs creates it and the platform folders.

Source PDF filename format
For consistency, use: YYYYMMDD_PLATFORM_PL_BATCH.pdf
Here PL means packing list. BATCH is 1, 2, 3, and so on as new PDFs arrive.

Examples:
  20260927_SPX_PL_1.pdf
  20260927_FLASH_PL_1.pdf
  20260927_Lazada_PL_1.pdf
  20260927_TikTok_PL_1.pdf

This filename pattern is recommended, not compulsory. The file must be an
original packing-list PDF with readable text; .pdf and .PDF are accepted.
The platform is recognized using the PDF layout and the courier rules below.
Renaming a screenshot, image, Word document or waybill to .pdf does not make
it a supported packing list.

How the program recognizes each platform
- Shopee SPX: use a folder named SPX, or include SPX as a separate label in
  the filename, such as 20260927_SPX_PL_1.pdf.
- Shopee FLASH: use a folder named FLASH, or include FLASH as a separate
  label in the filename, such as 20260927_FLASH_PL_1.pdf.
- A Shopee file named PICK AND PACKING LIST 8AM.pdf works when it is inside
  the correct SPX or FLASH folder. Uppercase/lowercase does not matter for
  those courier labels.
- Keep the courier label separate: SPX or SPX_Orders works; SPXOrders does
  not provide the separate SPX label the app looks for.
- Avoid placing both SPX and FLASH in the same file's folder path/name.
  For example, do not put FLASH files under a parent folder called SPX.
- Lazada and TikTok are recognized from the text and layout inside their
  PDFs. Their filenames are for organization; the recommended shared folder
  is LAZADA & TIKTOK.

Adding PDFs from Downloads or another folder
Click Add PDFs to copy files into the selected dated folder automatically.
Shopee files are recognized automatically from SPX or FLASH in their source
folder path or filename. If a generic Shopee PDF is in Downloads, rename it
with the correct courier label (for example 20260927_SPX_PL_1.pdf), or move it
into the correct SPX or FLASH folder before adding it. A path must identify
only one courier. Lazada and TikTok are recognized from their PDF contents.

Checking a different folder
1. Keep the same YYYYMMDD structure inside the new main folder.
2. Click Choose folder, check the selected date, and click Scan for new PDFs.
3. Confirm the expected filenames, platform labels and order counts appear.
   If no files appear, check the dated folder name and source PDF location.
   If a row needs attention, read its message before generating.
When moving previously processed work, copy the entire dated folder,
including 000 Output, its completed Word documents and both history files.
Older batches made before this app may have only Processed_Files.txt; keep
that log and their Word documents. The app verifies that earlier history.
Copying only PDFs into a fresh dated folder can make them appear unprocessed.

Daily steps
1. Click Choose folder and select your main packing folder, or the dated
   folder (for example 20260926). Check the date shown on screen.
2. Save downloaded PDFs in the SPX, FLASH, and LAZADA & TIKTOK folders.
   Alternatively click Add PDFs. The program copies them into the chosen
   dated folder and leaves the originals in place. Shopee files must have
   SPX or FLASH in their filename or source folder path.
3. Click Scan for new PDFs. New files and files missing their Word output
   are selected automatically. Processed files stay selectable: tick Use
   to generate them again. Click the checkbox in the Use column header to
   select all compatible PDFs, including processed ones. Click it again to
   clear all selections. A partial check means some eligible rows are selected.
   Files with errors or awaiting changed-file review are excluded until resolved.
   To view a file's contents, select its row and click Open selected PDF.
4. Click Generate Packing Lists. Wait until the completion window appears.
   Microsoft Word checks that each entire order fits on one A4 page.
5. Open the completed document and print with A4 paper in Word.

What is generated
- One Word document for SPX and one for FLASH, using orange tables.
- One combined Word document for Lazada and TikTok, using blue tables and
  separate platform labels. A batch containing only one of these platforms
  still uses the LAZADA_TIKTOK filename sequence.
- All files go in the selected dated folder's 000 Output folder.
- Each group uses the next suffix: _1.docx, _2.docx, _3.docx, and so on.
- Output suffixes are assigned by the program independently of the numbers
  in source PDF filenames. Keep the generated output and history filenames.
- The source PDF batches stay grouped. Each order has one bordered table,
  Number and Time writing lines, product check boxes, variation and pieces.

Product picking summary
Every generated document ends with a Product Picking Summary on a new page.
It lists the product, variation or size, and total pieces needed from inventory.
Each summary covers ONLY the orders in that document. Later batches get their
own summaries covering the PDFs selected for that run. Regenerating a PDF
also includes its orders again in that new document and summary.
The packing tables and picking summary use the names saved in Define Name.
A blank alternative product name keeps the original product name; a blank
alternative variation keeps the original variation. Each field works separately.
A dash represents a missing source variation. Sizes are not inferred or added.
Matching FINAL product names and variations have their pieces added together
in that document's picking summary. Define the same alternatives for different
listings only when you want their quantities combined. Pieces means packs or
bottles, not kilograms or liters. Use the Done boxes while collecting stock.
Long summaries continue onto additional A4 pages with repeated column headers.

New orders later in the day
Add the new PDFs and scan again. Generate creates the next batch.
Give later source PDFs a new filename, such as 20260927_SPX_PL_2.pdf, and
keep them in the same day's SPX folder. Keep earlier source files in place;
replacing a processed PDF triggers a changed-file review.
Existing batches are kept. Generating includes all orders in the selected
PDFs, including previously generated orders. An order repeated across the
PDFs selected in the same run appears once. Uncheck PDFs you do not want.
A renamed copy is identified as repeated and stays unchecked by default;
you can still tick it to generate another copy.

Generating or printing an earlier batch again
To make another Word copy, tick Use beside any processed PDF and click
Generate Packing Lists. You can combine it with other selected PDFs.
Each platform uses one more than its highest Word filename number still in
000 Output. Existing Word files are never overwritten.
Examples for one platform:
- No Word files remain: the next file is _1.
- _1 and _2 remain (you deleted _3): the next file is _3.
- _1 and _3 remain (you deleted _2): the next file is _4.
Gaps below the highest remaining number are not filled. SPX, FLASH, and
LAZADA_TIKTOK have separate numbering for each date.
To print an existing Word document, use Completed documents instead.

If you delete a generated Word file
Click Scan for new PDFs. The program checks which Word files still exist
inside this date's 000 Output folder and matches them to their source PDFs.
If orders no longer have a current Word output, the affected PDF rows show
Output missing and are selected automatically. Click Generate Packing Lists
to create a new numbered copy from those selected PDFs.
If another current copy still covers every order, the PDF remains Processed;
you can tick Use to generate it again anyway. A superseded revision does not
count as a current copy. Moving or renaming a Word file away from its recorded
name in 000 Output is treated as missing.
A PDF may contain both covered and missing orders. When selected, its full
contents are included in the new document. Its picking summary matches that
new document only.
Completed documents shows only Word files that still exist. Missing entries
are removed when you open the list, click Refresh list, or scan again.

Using Completed documents
The groups appear in this order: SPX, FLASH, Lazada + TikTok. Within each
group, files appear in numeric order: _1, _2, _3 ... _10.
Click the + beside a generated Word file to expand its included source PDFs.
Expand a PDF to see its order IDs, then expand an order to see the printed
product names, variations and pieces included in that document.
The displayed data belongs to that generated document, even if the source
PDF was changed afterward. If two selected PDFs share an order, that order
can appear beneath both source PDFs, but is printed once in the document.
Select any document, PDF or order and click Open Word document to view its
packing list. Select a source PDF or its order to use Open source PDF.
Refresh list removes any Word files deleted while this window is open.

How the file history works
Every generation records the selected source PDF paths, their file
fingerprints, linked order IDs, and the Word filename containing those orders.
Both the readable log and Processing_History.json retain these associations.
Scan also saves associations from earlier logged batches before a Word file
is deleted. Keep the source PDFs and both history files so these links remain
available; you do not need to delete history to generate again.
Changed PDFs still require Review changed file before their current contents
can replace an earlier version. Deleting a Word output does not bypass review.

Changed files - supervisor review
A changed file is marked for review and is not selected automatically.
Click Review changed file to compare the earlier and current order details.
- Keep earlier output records a decision to ignore the changed version.
- Create revision selects the changed file for a new, clearly marked
  revision document. This includes the file's orders again: check their
  previous packing status before using it. Click Generate to create it.
The log records which earlier orders or documents the revision replaces.
Conflicting versions of an order in two current PDFs must be resolved by
the supervisor before those PDFs can be processed.

If a file needs attention
Read the Status column; hover over a shortened message to see it in full.
The app stops on unreadable quantities,
unfamiliar layouts, scanned PDFs, duplicate labels inside one PDF, and
multi-package or continued-page labels. Download the original packing list
or ask the supervisor to review it. It does not guess missing information.
If an order cannot fit on one A4 page, no completed batch is recorded.
If Word needs setup or shows a dialog, finish that in Word and try again.

Files to keep
Keep source PDFs, completed Word documents, Processed_Files.txt and
Processing_History.json together. Back up the whole dated folder.
The text log is readable. The JSON file stores exact fingerprints and order
history for the program. Do not manually edit or delete either history file.
A .packing-transaction.json file means a batch commit was interrupted; the
app recovers it on the next scan. Leave it in place for the app to recover.

Moving the application
Copy the whole Packing List Manager folder. Use Choose folder on the new
computer to select the dated source folders. Word must be installed.
The current workflow is designed for one operator on one computer at a time.

Supported sample layouts
Shopee: A4 PDFs with up to four packing labels per page (SPX and FLASH).
Lazada: order-level packing lists with four item columns.
TikTok: one order per page with Product Name, SKU, Seller SKU, Qty and Qty Total.
If an online shop changes its PDF format, the parser may need an update.

Define Name - standard product names
Click Define Name near the bottom of the main window. The program remembers
one row per exact original product name and variation found in scanned PDFs,
across dates and source folders. Unsupported PDFs do not add guessed items.
Use Search to find a product. The alternative columns are highlighted orange.
You may edit all four columns, add a row, or select rows and click Delete selected.
Click Save names to apply direct edits. Clearing an alternative restores the
original value for that field. Original names and variations are exact matches.
Changing an original field changes which PDF text that definition matches.

A nonempty alternative must begin with a letter or number, with no leading space
or symbol. Afterwards, letters, numbers, spaces, and these common symbols are
allowed: - ( ) / % . + , & apostrophe. A newline or tab is not a valid name.

Deleting a row and saving removes its alternatives. If the same original pair
is found on a later PDF scan, it is added as a NEW row with blank alternatives.
Opening Define Name alone does not rediscover deleted rows.

Temporary Excel editing
Desktop Microsoft Excel is required for these two small buttons.
1. Export starts enabled; Import starts disabled.
2. Click Export. Direct edits are saved and the program opens an Excel workbook
   from an internal temporary folder. It is not saved in your source folder.
   Export becomes disabled and Import becomes enabled. The grid is temporarily
   read-only so Excel and the grid cannot overwrite each other's edits.
3. Edit original names, original variations, and/or alternatives in Excel. Add
   new rows if needed. Keep the Names sheet and its four visible headings.
   Hidden row IDs preserve a row's identity when you edit its original fields.
4. KEEP THIS EXCEL WORKBOOK OPEN. Finish editing the current cell, then click
   Import in Define Name. The program saves Excel automatically, validates all
   rows, updates the saved names, closes that workbook, and removes its temporary
   file. Export becomes enabled and Import becomes disabled again.
5. If the workbook was closed first, Import displays:
   Error: No file has been detected
   Please do not exit excel file before clicking import
   The buttons reset. Click Export to start again from the program's saved names.

Invalid Excel names, duplicates, changed headings or formulas stop the import
without changing saved names. Keep Excel open, correct the reported rows, and
click Import again. Use plain text for all name fields. Blank alternatives clear
those alternatives. Rows omitted from Excel remain in the program; use Delete
selected in Define Name to remove them. Closing Define Name with Excel pending
asks before discarding those unimported changes. Other Excel workbooks remain open.

These definitions affect FUTURE generated files. Existing Word documents and
their saved contents stay unchanged. To use new names for an already-processed
PDF, select its Use checkbox and generate another document.

Saved definitions
ProductNames.json in the Packing List Manager application folder stores the
names for this installation. ProductNames.json.bak keeps the preceding saved
catalog. Keep these with the application when moving or backing it up. If the
catalog becomes unreadable, restore a valid backup; the app does not silently
replace it. The temporary Excel workbook is an editing session, not a backup.
